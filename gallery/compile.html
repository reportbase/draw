tvf compile time tvf.compile.js

"Geometry is compile time": the addresses, the corner, the flip and the levels are laid before anything arrives, with no branches, and the payload, the values met there, is runtime, where every "if" belongs. The question left is whether compile time itself has logic, and whether a creator can add some when it makes a universe.

Compilers have a precise answer, partial evaluation. Split a program's inputs into those fixed before it runs and those that arrive; run, ahead of time, every step and every branch that needs only the fixed ones; what is left is runtime. This page does that to a reader's own programs, live, so the question is run rather than argued. The framing is Serial, Parallel and Nowhere's opening (in the wander repository); the answer here is a reading, not a ruling.

compile time and runtime where the if lives can compile time have logic?
tvf.compile.js is a small partial evaluator: a language of numbers, names, arithmetic, calls, if, let, for and while; a folder that runs everything a program's fixed inputs decide and returns the rest; a census of what is left; and the reader's programs (reading one place, detail by recursion, detail by level), with the level read from a float's exponent bits and two ways of creating one universe.
The number to carry off: with the geometry fixed, the reader left for runtime has one branch, the side of the corner, and it is the payload's; and a universe created by logic and one written out by hand are bit for bit the same from inside.

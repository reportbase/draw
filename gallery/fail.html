tvf where it breaks tvf.stress.js

The other five pages are the case for the format. This one is the case against it, and it is the more useful page, because every number on it was measured in your tab when you scrolled past — nothing here is a remembered result from a run I did earlier. A failure worth showing is a failure you can reproduce; a failure worth trusting is one the same harness would have reported clean if it had come out clean.

Four kinds of thing are on this page, and they are not the same kind. There is a real bug — found while building this, now fixed, kept reproducible so you can watch it happen. There are consequences of the band limit, which are not bugs and will never be fixed because they are the price of the guarantee. There are traps, which pass the test you would think to write and fail the one that matters. And there are structural limits that no amount of implementation effort touches. At the bottom is the half of the bargain that makes the rest credible: the things that did not break, including two I had written down as broken and which turn out not to be.

tvf.stress.js is the harness. Each failure is a function that returns measured numbers, so the page reports rather than asserts, and node stresstest.mjs runs the same functions with assertions on top.
The old resample() is kept in the harness as lerpResample() — not out of sentiment, but because a bug you can no longer reproduce is a bug you have to take on faith.

The writing behind the editor. One specification, of the .tvf format the editor reads and writes, and the theorem the format is an instance of, the Tangent Bridge: a closed curve held as N leaves and presented continuously between them, exact at the leaves and bounded in between. The theorem comes in two presentations and a spectral companion with its newest section. Each paper is a Markdown file in papers/; read opens it here, with the mathematics typeset.

In reading order. The galleries are the same claims run live: where a paper's result has a page that shows it, the page is named under the paper.
